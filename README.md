# Bioinformatics Python Exercises

Beginner-friendly Jupyter notebooks for MSc students learning Python, scientific computing, and bioinformatics CSV processing.

## Files

### Level 1: Basic Python

- `level_01_python_variables_and_types.ipynb`: practise variables, numbers, strings, and simple calculations.
- `level_02_python_lists_and_indexing.ipynb`: practise lists, indexing, adding/removing items, and summary functions.
- `level_03_python_loops_and_conditions.ipynb`: practise `for` loops, `if` statements, and filtering values.
- `level_04_python_functions.ipynb`: practise writing reusable functions.
- `level_05_python_strings_and_dna_sequences.ipynb`: practise string operations with DNA sequences.
- `level_06_python_dictionaries_and_records.ipynb`: practise dictionaries and list-of-dictionary records.

### Level 2: Scientific Python

- `level_07_numpy_arrays_for_bioinformatics.ipynb`: practise NumPy arrays before using SciPy.
- `level_08_scipy_statistics_ttest.ipynb`: use SciPy statistics to compare two groups.
- `level_09_scipy_distances.ipynb`: use SciPy to calculate distances between samples.
- `level_10_scipy_clustering.ipynb`: use SciPy hierarchical clustering and dendrograms.

### Level 3: Bioinformatics CSV Processing

- `level_11_pandas_load_gene_expression_csv.ipynb`: load a CSV, inspect rows and columns, calculate simple statistics.
- `level_12_pandas_clean_sample_metadata.ipynb`: find missing values, fill or remove them, save a cleaned CSV.
- `level_13_pandas_filter_genomic_variants.ipynb`: filter genomic variants using biological criteria.
- `level_14_pandas_merge_gene_annotations.ipynb`: combine two CSV files using a shared gene column.
- `level_15_pandas_microbiome_summary.ipynb`: summarise count data, calculate relative abundance, and plot results.

## Suggested Order

Start at `level_01` and continue in order. Each notebook includes examples followed by practice exercises.

## Requirements

The notebooks use:

- Python 3
- pandas
- matplotlib
- numpy
- scipy

If needed, install them with:

```bash
pip install pandas matplotlib numpy scipy jupyter
```
